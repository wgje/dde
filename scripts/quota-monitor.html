授权弹窗会复用当前浏览器的登录会话。这里登记已创建 OAuth App 的 Client ID；Client ID 与 Cloudflare Account ID 保存到本机忽略目录。Client Secret 只保存在本次进程内存；需要跨重启时放入未提交的 .env.local。

先按下面的步骤在平台控制台创建或核对 OAuth App，再回到本机填写 Client 信息。浏览器已登录的平台会话可复用，但仍须逐项同意本机请求的权限。

Cloudflare：创建并核对 OAuth Client
  1. 在 Cloudflare 账户中打开 Manage Account → OAuth clients → Create client，创建仅供本机使用的客户端。
  2. 选择 Authorization Code、响应类型 code；按浏览器/桌面应用方式启用 PKCE（S256），Token authentication 选 none。这种 PKCE 公共客户端不需要 Client Secret，下面的 Secret 可留空。
  3. 把上方 Cloudflare 回调地址原样加入 Redirect URLs（不要换成 Supabase 的回调，也不要改端口或路径）。
  4. 只选账户分析只读权限：在 OAuth Client 的 Scopes 中勾选 Account Analytics Read。额度观察簿固定请求 account-analytics.read，本页无需编辑授权范围。若 App 未允许该范围，请先在控制台调整并保存，然后重新发起授权。
  5. 创建后复制 Client ID；Cloudflare Account ID 可从所选账户主页 URL 中取得。填入下方并保存。
Cloudflare 官方创建指南打开 OAuth Clients
Supabase：创建并核对 OAuth App
  1. 在 Supabase 组织设置打开 OAuth Apps → Add application，创建或选择一个供本机监控器使用的 App。本机回调使用 localhost 主机名以符合 HTTPS/loopback 校验；主页面仍可从 127.0.0.1 打开。
  2. 把上方 Supabase 回调地址原样登记为 Redirect URL；权限仅选 Projects: Read 与 Secrets: Read，它们分别用于列出项目和读取 Metrics API 所需的项目 Secret API Key。
  3. 保存后复制 Client ID 与 Client Secret，填入下方并保存。Secret 不会写入本地配置文件；重启监控器后需重新填写，或按本页外的本地 .env.local 说明配置。

重要：Secrets: Read 可读取该项目全部 API Keys 和 Secrets，不是 Metrics-only 权限。若不接受此范围，不要授权 Supabase OAuth；请改用备用方式中的专用 Metrics Secret Key。

遇到“OAuth endpoint returned 403”：该错误发生在授权回调后的 token 兑换阶段。请确认编辑表单点过 Confirm 保存；Supabase OAuth App 已按官方流程 Publish；本地 Client ID 与 Client Secret 属于同一个 App；并且已选 Projects: Read、Secrets: Read。上方显示的完整回调地址必须逐字登记。失败的授权码是一次性的，请修正后回到本页重新发起，不要重用旧回调链接。

口径与项目映射说明

Cloudflare D1 / KV 为账户级聚合；当前仓库未发现对应 Wrangler 绑定，账户读数可能来自其他项目。R2 标准层 Free 基线为 10 GB-month、Class A 100 万次、Class B 1,000 万次；Class A/B 仅按已知 actionType 计数，遇到未知类型会 fail-closed，存储仍只显示当前快照而不是账期 GB-month。Supabase Metrics API 返回的 Prometheus 指标中，目前只把数据库大小映射到额度；Egress、Storage、MAU、Edge Function 和 Realtime 账期指标尚未映射，不能靠技术序列数推算，也不会估成 0。

从 Supabase Usage Dashboard 记录账期读数

仅作为人工记录，不替代 Metrics API 快照。每条保留项目、账期、来源、读数的原始显示字符串与录入时间；Dashboard 值可能四舍五入。空白仍表示未观测，Dashboard 明确显示 0 才是零。请先在 Usage 页选择目标项目与账期；Storage 输入框记录 Dashboard 当前 GB 摘要，不等同于账期 GB-hours；Logs Query 是 allowance 参考而非直接计费。
