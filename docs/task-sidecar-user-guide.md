# 任务僚机使用指南

> 面向对象：NanoFlow 用户。本文说明任务僚机解决什么问题、它如何工作、在哪里能看到，以及如何正确使用。

## 这是什么

任务僚机是任务块上的一层“注意力提示”。它不会改变任务的父子结构，也不会新增流程图连线，而是把任务当前最值得注意的信息浓缩成任务块内的总控、外置短徽标、悬停提示和可编辑注意事项。

它适合回答一个很常见的问题：我不点开任务详情时，能不能一眼知道这个任务要注意什么？

## 解决的问题

### 不点开任务也能看见重点

以前在 Flow 视图里，任务块主要展示标题和层级。用户如果想知道风险、等待时间、资料、标签或其他提醒，需要点开详情或切到 Text 视图。

任务僚机会把这些信息压缩成短徽标，例如：

- `风险1`
- `等待20m`
- `高负荷`
- `注意1`

这样在扫流程图时，可以更快判断哪些任务需要优先处理。

### 避免用更多连线表达注意事项

流程图已经有父子节点和关联块。如果再把“注意事项”做成节点或连线，大任务会变成很多线条叠在一起，阅读负担会更高。

任务僚机采用任务块外侧的小翼提示，不新增节点，不新增连线，不参与图拓扑。它只是帮助扫读，不改变任务之间的真实关系。

Flow 图上默认只在任务块内部显示一个僚机总控按钮，避免画布被提示块铺满。点击总控后，僚机触发点会自然分散在任务块周围，整体偏右上展开，数量多时再向上、左、下补位。每个触发点使用独立的琥珀色视觉样式，并用很短的琥珀色引导线贴回任务块。

每个项目会记住你展开过哪些任务的僚机。下次回到同一项目时，这些任务仍会保持上次的展开或收起状态。

这些虚线只是任务块内部的装饰引导线，不是父子线或跨树关联线：没有箭头，不可点击，不参与拓扑，也不会成为新的连接关系。

### 大图里可以减少关联线干扰

当一个大任务有很多跨树关联时，Flow 图可能会出现大量关联线。现在可以切换关系降噪模式：保留任务之间的真实关联数据，但按需要减少画布上显示的跨树关联线。

关系降噪只影响 Flow 画布显示，不会删除连接，也不会影响 Text 视图或同步。关联块本身已经在画布上可见，不会再重复显示成任务僚机。

### Flow 与 Text 视图保持一致

同一个任务的僚机信息会在 Flow 与 Text 两种视图里复用同一套规则。你在 Text 视图编辑的注意事项，会在 Flow 详情和任务块摘要中体现；Flow 详情里编辑的注意事项，也会回到 Text 视图。

### 离线和多端同步不丢注意事项

可编辑注意事项会保存到任务自己的 `attentionMeta` 字段。它和任务内容一样走本地先写、后台同步、失败重试的路径。

这意味着：

- 离线时可以继续编辑。
- 联网后会自动同步。
- 多端冲突时会按任务更新时间和字段锁规则合并。
- 同步查询、批量写入、全量加载和初始化脚本都包含该字段，避免某条读取路径丢失僚机内容。

## 实现方法

### 使用“摘要层”，不是新节点

任务僚机只显示在任务块外侧或任务详情里，不会创建新的流程图对象。Flow 图里仍然只有任务节点、父子线和关联线。

这样可以在不增加线条复杂度的前提下，让任务块携带更多上下文。

### 自动推导已有信息

系统会从任务已有字段里推导一部分僚机摘要：

| 信息来源 | 显示效果 |
| --- | --- |
| 高优先级或紧急优先级 | `风险1` |
| 已过期或临近截止 | `风险1` |
| 等待时间 | `等待20m` |
| 高认知负荷 | `高负荷` |
| 预计耗时 | `预计30m` |
| 附件或知识锚点 | `资料1` |
| 停泊、入坞、专注中 | 状态提示 |
| 标签 | 显示前几个标签 |

### 支持用户手动填写注意事项

阶段二新增了可编辑的注意事项。你可以把任务最需要提醒自己的点写成多行文本，每行一条。

示例：

```text
Token 过期前要刷新
接口字段还没冻结
等对方确认报价
```

系统会把未完成的注意事项变成多个独立僚机触发点。任务块内的僚机总控会显示提示数量；点击总控展开后，任务块周围只显示紧凑编号或短提示；鼠标悬浮到某个僚机触发点时，才显示对应注意内容。悬浮任务块本身不会展开全部注意，避免扫图时被大段文字遮挡。

### 与待办事项保持分离

待办事项是任务正文里的 Markdown checklist，用来记录“要做什么”。任务僚机是注意力摘要，用来记录“做这个任务时要注意什么”。

两者不会互相替代：

- 待办事项继续显示在 Text 视图的待办区、任务正文和 Markdown checkbox 中。
- 任务僚机不再把正文里的未完成待办显示成 `待办N`。
- 如果某个待办背后有风险或前提条件，建议把风险或前提单独写进僚机注意事项。

### 提供关系显示模式

Flow 工具栏新增关系降噪按钮，可以在三种模式之间切换：

| 模式 | 作用 |
| --- | --- |
| 全部关联 | 显示所有跨树关联线，适合完整检查关系。 |
| 聚焦关联 | 只显示当前选中任务相关的跨树关联线，适合查看某个任务的上下游关联。 |
| 隐藏关联 | 隐藏所有跨树关联线，适合在大图里专注父子结构和任务块本身。 |

无论使用哪种模式，关联数据都不会被删除。任务僚机不再把关联块重复显示成 `关联N`，避免同一条关系在画布上出现两次。

### 不包含智能僚机

当前版本不接入 AI、LLM 或自动生成注意事项。僚机信息来自两类来源：

- 任务已有字段自动推导。
- 用户手动填写的注意事项。

## 在哪里可以使用

### Flow 视图任务块

Flow 图中的任务块内部会显示僚机总控按钮。它适合快速扫图，判断哪些任务有风险、等待、资料或手动注意事项。点击总控后，任务块周围会伸出分散的僚机触发点；悬浮到触发点时，可以查看对应注意的具体内容。

桌面端可以把鼠标悬停在任务块上查看更完整的提示。移动端为了减少误触，不使用悬停提示，建议点开详情查看。

### Flow 工具栏关系降噪

Flow 工具栏里有一个关系降噪按钮。每点击一次，会按以下顺序切换：

1. 全部关联。
2. 聚焦关联。
3. 隐藏关联。
4. 再回到全部关联。

建议用法：

- 想完整检查任务之间的关系时，使用“全部关联”。
- 图上连线太多、但只想看当前任务相关连接时，先选中任务，再切到“聚焦关联”。
- 想整理父子结构或扫任务僚机徽标时，切到“隐藏关联”。

### Flow 任务详情

点开 Flow 任务详情后，可以看到“任务僚机”摘要区。编辑模式下会出现“僚机注意事项”输入框。

使用方式：

1. 点击任务块打开详情。
2. 切换到编辑模式。
3. 点击“添加注意”创建一条注意事项。
4. 在新增的输入框里写入提醒内容。
5. 需要多条时继续点击“添加注意”。
6. 注意超过 3 条时会默认收起，点击“展开”查看全部。
7. 点击每条右侧的删除按钮即可移除该条注意事项。

### Text 视图任务卡片

Text 视图的折叠任务卡片会显示同一套僚机徽标。你可以在列表里直接看到任务的风险、等待、资料和注意事项，不必逐个展开。

### Text 任务编辑器

打开 Text 任务编辑器后，在编辑状态可以看到“僚机注意事项”输入框。

使用方式：

1. 进入 Text 视图。
2. 展开或编辑一个任务。
3. 点击“添加注意”创建一条注意事项。
4. 在输入框中填写内容；需要多条时继续添加。
5. 注意超过 3 条时会默认收起，点击“展开”查看全部。
6. 点击每条右侧的删除按钮可以移除该条注意事项。
7. 系统会即时本地保存，并在后台同步。

### 冲突解决界面

如果同一个任务在多端发生冲突，任务僚机字段会出现在冲突差异里，标签为“任务僚机”。这样用户可以知道注意事项是否被本地或远端修改过。

## 推荐写法

### 适合写进任务僚机的内容

- 外部依赖：`等设计确认图标尺寸`
- 风险提醒：`接口字段还没冻结`
- 操作前提：`先备份当前配置`
- 不适合放进标题的短提醒：`上线前再跑一次权限检查`
- 暂时不想拆成子任务的注意点：`和移动端一起验证`

### 不建议写进任务僚机的内容

- 很长的方案说明。长内容更适合写在任务正文。
- 正式任务关系。任务之间的依赖仍然应该使用父子节点或关联块。
- 已经完成的历史记录。任务僚机更适合保留当前还需要注意的事项。

## 常见问题

### 为什么 Flow 图里只显示几个短徽标？

任务块空间有限。短徽标用于扫读，完整内容放在详情、Text 编辑器和桌面悬停提示里。

### 关联块会被算进任务僚机吗？

不会。父子关系和跨树关联块都已经由流程图结构表达，不会重复算进任务僚机。

### 隐藏关联线会删除连接吗？

不会。关系降噪只改变 Flow 画布的显示方式，不删除任何连接。切回“全部关联”后，跨树关联线会重新显示。

### 清空输入框后会发生什么？

手动注意事项会被清空。自动推导的风险、等待、资料、标签等仍会继续显示。正文里的 Markdown 待办不会被影响。

### 离线编辑安全吗？

可以离线编辑。编辑会先写入本地，联网后后台同步。如果同步失败，会进入重试队列。

### 当前会自动帮我生成注意事项吗？

不会。当前版本没有智能僚机，也不会调用 AI 自动生成内容。

## 当前范围

已完成：

- Flow 任务块短徽标。
- Flow 桌面端悬停提示。
- Flow 任务详情摘要和编辑入口。
- Flow 关系降噪模式：全部关联、聚焦关联、隐藏关联。
- Text 任务卡片摘要。
- Text 任务编辑器编辑入口。
- 可同步的 `attentionMeta` 数据字段。
- 离线优先写入、后台同步、冲突差异展示。

暂不包含：

- 智能僚机或 AI 自动生成。
