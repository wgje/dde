# Focus 专注模式

Focus 专注模式用来把完整项目收窄成当前时段真正要处理的少量事项。它不是第二个任务系统，而是帮助你从“所有事情”切换到“现在只看这些”。

## Focus 里的几个概念

| 概念 | 含义 | 使用建议 |
| --- | --- | --- |
| Gate | 进入专注前的处理入口 | 先清理 Black Box 和待判断项 |
| Black Box | 快速记录箱 | 记录后要复盘，不能长期堆积 |
| Focus 队列 | 当前时段要看的少量任务 | 不要放完整项目 |
| Strata | 从历史沉积里找回需要继续处理的项 | 只恢复真的要继续的内容 |
| Snooze 打盹 | 暂时推迟处理 | 每天有次数上限，不要滥用 |

## 什么时候进入 Focus

适合进入 Focus 的时刻：

- 你准备开始一段连续工作；
- 当前任务列表太大，看着分心；
- Black Box 里有需要先处理的记录；
- 你需要把今天的目标限制在少数几件事；
- 停泊坞里有任务到了该处理的时间。

不适合进入 Focus 的时刻：

- 你只是想批量整理所有项目；
- 你还没有把任务标题写清楚；
- 你只是想快速记一个想法；
- 你需要看复杂关系图。

## 如何处理 Gate

Gate 的作用是把入口处的杂项变成明确决定：

1. 先看 Black Box 记录。
2. 判断每条记录是任务、资料、噪声还是稍后再看。
3. 是任务就转成任务。
4. 是资料就挂到已有任务或放到外部知识库。
5. 是噪声就丢弃。
6. 暂时判断不了再打盹，但不要无限打盹。

Gate 不是垃圾桶。它是把“未处理输入”变成“明确状态”的地方。

## 如何选择专注任务

专注队列建议控制在 1 到 3 个任务。选择时优先考虑：

- 今天必须推进；
- 已经具备资料；
- 能在当前时间块内完成或明显推进；
- 和当前目标直接相关；
- 不需要等待别人回复。

不要把这些内容放进 Focus：

- 整个项目；
- 大量只是可能会做的任务；
- 已经阻塞且没有下一步的任务；
- 只是资料而不是行动的内容。

## Strata 什么时候用

Strata 适合处理“以前沉下去，现在又需要”的内容，例如：

- 曾经完成的任务有后续；
- 以前忽略的 Black Box 记录重新变重要；
- 某个历史事项需要恢复到当前工作；
- 你需要从旧上下文里找回可行动线索。

恢复前先问自己：这条内容现在是否有明确下一步？如果没有，先不要恢复。

## 限制和注意事项

| 项目 | 当前规则 |
| --- | --- |
| 语音转写每日额度 | 50 次 |
| Gate 打盹次数 | 每天最多 3 次 |
| 手机端默认 | 仍然以文本视图为主 |
| Focus 队列定位 | 当前时段工作队列，不是长期计划 |

如果 Focus 里堆满任务，说明你需要回到文本视图整理，而不是继续往 Focus 塞内容。
