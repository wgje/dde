# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab and go to **Advisories**.
2. Select **Report a vulnerability** and submit the report privately to the maintainers.
3. Include the affected area, impact, reproduction steps, and any relevant version or commit information. Avoid including real user data, credentials, or secrets; redact them from evidence.

Private vulnerability reporting is enabled for `wgje/dde` as of 2026-11-14. Do not disclose vulnerability details, proof-of-concept code, credentials, or sensitive user data in public Issues, Pull Requests, or Discussions. Please coordinate any public disclosure with the maintainers after a fix or mitigation is available.

## Scope and expectations

This repository does not currently publish a supported-version matrix, response-time commitment, or bug-bounty program. Maintainers will assess reports and coordinate follow-up through GitHub's private reporting workflow; response timing is not guaranteed.

If GitHub's private reporting control is unavailable, do not post technical details publicly. Ask a repository maintainer through an existing trusted channel to establish a private route first.
